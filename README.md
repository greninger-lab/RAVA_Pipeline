# ARTICLE PLACEHOLDER
This repository contains the code and data used in the publication **"Chikungunya virus persists in joint associated macrophages and promotes chronic disease"** by **Zarrella** et al. (2025).

## What is RAVA?
RAVA is derived from [LAVA](https://www.biorxiv.org/content/10.1101/2019.12.17.879320v1). RAVA takes FASTQ files (for every sample in your analysis), a metadata sheet (providing info on what day or passage each sample was collected), and a reference genome (your own FASTA and GeneBank files). RAVA outputs an interactive graph (viewable in a web browser), a SNV table for all analyzed samples, and intermediate analysis files.

FASTQ files must be trimmed before running the pipeline.

## Input files
We used only R1 reads for this study. Raw read files are available in BioProject PRJNA1247591.

QC filter and trim raw reads with fastp using the following parameters:

```bash
  fastp -i <raw_reads_file_name>.fastq.gz \
    -o "trimmed/<reads_trimmed_file_name>.fastq.gz" \
    --cut_mean_quality 20 \
    --cut_front --cut_tail \
    --length_required 20 \
    --html "fastp_reports/html/<file_name>_report.html" \
    -j "fastp_reports/json/<file_name>_report.json" \
    --low_complexity_filter \
    --trim_poly_g \
    --trim_poly_x
```

You can downsample QC filtered inoculum stocks (P0) reads using the following commands:
```bash
seqtk sample -s112 <(gunzip -c kz_01_04b_input.fastq) 1000000 > kz_01_04b_input_1Msubsample.fastq
seqtk sample -s112 <(gunzip -c kz_01_04b_input.fastq) 1000000 > kz_01_04b_input_1Msubsample.fastq
```

## Runing profiling of inoculum stocks used in animal experiments

We used Chikungunya virus strain AF15561 (EF452493.1) as the reference, with degenerate nucleotides replaced by the most common base in the inoculum stocks, since the RAVA pipeline does not support degenerate bases. Reference files and an example samplesheet are available in the `references/` and `samplesheets/` directories, respectively.


```bash
nextflow run greninger-lab/RAVA_Pipeline -r 2024-12-09_CU_KZ_CHIKV_publication \
--OUTDIR results/inoculum_results/ \
--GFF ./references/AF1556_no_degen_nts_RAVA_ref.gb \
--FASTA ./references/AF1556_no_degen_nts_RAVA_ref.fasta \
--METADATA ./samplesheets/inoculums_samplesheet.csv \
-with-docker ubuntu:18.04 \
-profile Cloud
```

## Running RAVA on animal derived samples

Consensus genomes for the inoculum stocks were generated by majority rule in Geneious Prime 2025.0, using the Chikungunya virus strain AF15561 (EF452493.1) as the reference. Both consensus genomes were identical, therefore we used only one of them (kz_01_04b_input) for the RAVA analysis of animal-derived samples. Reference files and an example samplesheet are available in the `references/` and `samplesheets/` directories, respectively.

```bash
nextflow run greninger-lab/RAVA_Pipeline -r 2024-12-09_CU_KZ_CHIKV_publication \
--OUTDIR results/animal_results/ \
--GFF ./references/2024-12-09_kz_01_input_RAVA_ref.gb \
--FASTA ./references/2024-12-09_kz_01_input_RAVA_ref.fasta \
--METADATA ./samplesheets/animal_samplesheet.csv \
-with-docker ubuntu:18.04 \
-profile Cloud
```

## Output files

Pre-generated RAVA analysis files (RAVA interactive plots, SNV info tables, and vcf files) can be found in `results` directory.

## Paper Figures

The `paper_figures/` subfolder contains the Jupyter notebook used to generate the figures for the manuscript, along with all required input and output files.

- *Input files*: Coverage files for all samples, generated using the RAVA pipeline (see above for details).
- *Output files*: Figures produced by the notebook.
