# Identification and characterization of two structurally distinct small-molecule SARS-CoV-2 assembly inhibitors
This repository contains the code and data used in the publication **"Identification and characterization of two structurally distinct small-molecule SARS-CoV-2 assembly inhibitors"** by **Karimi** et al.

## What is RAVA?
RAVA is derived from [LAVA](https://www.biorxiv.org/content/10.1101/2019.12.17.879320v1). RAVA takes FASTQ files (for every sample in your analysis), a metadata sheet (providing info on what day or passage each sample was collected), and a reference genome (your own FASTA and GeneBank files). RAVA outputs an interactive graph (viewable in a web browser), a SNV table for all analyzed samples, and intermediate analysis files.

FASTQ files must be trimmed before running the pipeline.

## Input files
We used only R1 reads for this study. Raw read files are available in BioProject PRJNA1271565.

QC filter and trim raw reads with fastp using the following parameters:

```bash
  fastp -i <raw_reads_file_name>.fastq.gz \
    -o "trimmed/<reads_trimmed_file_name>.fastq.gz" \
    --cut_mean_quality 20 \
    --cut_front --cut_tail \
    --length_required 20 \
    --html "fastp_reports/html/<file_name>_report.html" \
    -j "fastp_reports/json/<file_name>_report.json" \
    --low_complexity_filter \
    --trim_poly_g \
    --trim_poly_x
```


## Running RAVA 

The consensus sequence of “SARS-CoV-2 VOC omicron BA.4” was generated by majority voting in Geneious Prime 2024.0 with alignment to ON780481 and then used as a reference in RAVA analysis. Reference files and an example samplesheet are available in the `references/` and `samplesheets/` directories, respectively.

```bash
nextflow run greninger-lab/RAVA_Pipeline -r v1.0 \
--OUTDIR results/ \
--GFF ./references/2024-07-17_SARS-CoV-2_VOC_omicron_BA-4_consensus.gb \
--FASTA ./references/2024-07-17_SARS-CoV-2_VOC_omicron_BA-4_consensus.fasta \
--METADATA ./samplesheets/RAVA_samplesheet.csv \
-with-docker ubuntu:18.04 \
-profile Cloud
```

## Output files

Pre-generated RAVA analysis files (RAVA interactive plots and SNV full info table) can be found in `results` directory.
